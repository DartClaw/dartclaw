### F5 closer inspection

The named bounded reader has four direct production callers: runtime WhatsApp webhook, GitHub webhook and MCP router, plus Google Chat. Failed-auth emission has six: runtime gateway middleware, login, WhatsApp, GitHub and MCP, plus Google Chat. The proxy resolver also directly serves gateway and MCP rate limiting. No shared proxy helper or suitable public webhook byte reader exists in core/kernel today.

The functions consume a body stream/content length, socket peer/forwarded header/trusted proxies, and audit fields. Shelf exposes each directly. Small extraction functions are sufficient; no neutral request interface or injected service is necessary. Core need not learn `shelf.io.connection_info`; adapters extract the socket peer and pass it as a value. Core alone decides whether to trust the forwarded address.

The webhook copies append a chunk before checking the bound. The [runtime JSON reader](../../../../dartclaw-public/packages/dartclaw_runtime/lib/src/api/api_helpers.dart):77–96 and Google Chat's `readJsonObject` check before buffering. Those directly connected loops should also call the shared byte primitive, with their existing decoding and Response behavior retained. Unrelated QMD/process readers have different contracts and are outside this change.

Shelf is already a dependency of runtime and Google Chat, but not core. Adding it would not violate the workspace tier rule; it would widen core's dependency contract. The neutral functions avoid that widening with a small mapping cost, correcting the earlier assumption that they required substantial adapter machinery.

### Start-surface evidence

Backend support rechecked on 2026-09-20: [DatabaseConfig](../../../../dartclaw-public/packages/dartclaw_kernel/lib/src/database_config.dart) defines both engines and defaults to SQLite; [backend selection](../../../../dartclaw-public/packages/dartclaw_core/lib/src/storage/database_backend_selection.dart) instantiates either engine. The 0.26 change added PostgreSQL alongside SQLite, not as its replacement. Both remain covered by the shared storage contracts; no SQLite deprecation was found. This establishes product support, not the owner's deployment configuration.

`WorkflowService.start()` constructs the run at :278–289 and is the persistence convergence point. Runtime [workflow tools](../../../../dartclaw-public/packages/dartclaw_runtime/lib/src/mcp/workflow_tools.dart):49–68, [workflow routes](../../../../dartclaw-public/packages/dartclaw_runtime/lib/src/api/workflow_routes.dart):426–448, and [GitHub webhook](../../../../dartclaw-public/packages/dartclaw_runtime/lib/src/api/github_webhook.dart):156–168 call it without origin today. Form and JSON routes share the start helper but are distinct ingress paths (:65–71).

CLI has both paths: [standalone start](../../../../dartclaw-public/apps/dartclaw_cli/lib/src/commands/workflow/workflow_run_command.dart):289 calls the service; [connected start](../../../../dartclaw-public/apps/dartclaw_cli/lib/src/commands/workflow/api_workflow_connection.dart):120 posts the common API and currently supplies no client-surface metadata. [Scheduling wiring](../../../../dartclaw-public/packages/dartclaw_runtime/lib/src/runtime/scheduling_wiring.dart) composes scheduled turns; no separate workflow-start call was found there. The plan must propagate scheduled-turn context into `workflow_run`, not invent a second scheduler.

## Confidence and filter

Confidence is high for the observed ownership/topology/storage facts and the revised F5 seam's feasibility. Scores and chosen shapes are design judgments, not empirical benchmarks; F5's dependency containment comes with a small field-extraction cost.

The initial reviewer validated all five recommendations, but that did not replace the omitted owner gates. The owner accepted that revised F5 recommendation on 2026-09-20. F1–F4's original review findings remain unchanged: safe binding-load order, a shared expected-pending resolution critical section, and one replacement schema transition rather than accumulated migration paths.
