## Method notes that cost time

- Verify UI with real pointer and keyboard input and `elementFromPoint`, never with dispatched events or style reads alone.
- **Measure before you believe a rendering hypothesis.** Three plausible causes for the axe contrast `incomplete` — the transcript mask, the absolutely-positioned dock, the 200% zoom — were each disproved by probe. `elementsFromPoint` at an element's own centre is the cheap decisive test.
- The layout canon gate's own message is the fastest diagnostic surface: putting the stack and row rects into the clipping violation located the queue-row overflow in one run.
- A grid item's automatic minimum size is `min-content`. `.composer-stack` already documented this trap; `.conversation-queue` hit it again. Reach for `grid-template-columns: minmax(0, 1fr)` plus `min-width: 0` on the flex child.
- `dart run dev/tools/embed_assets.dart` must be rerun after design-system, template, static-asset or controller edits; the embedded copies are gitignored.
- Run the format check alone and read its exit code.
- The shared working tree holds other sessions' half-finished edits and the real git index holds a stale pre-staged set. Commit by path from a temporary index (`GIT_INDEX_FILE`, `git read-tree HEAD`, `git add <paths>`, `git hash-object -w` + `git update-index --cacheinfo` for a file whose hunks are mixed). Verify in a scratch worktree, never in the main checkout.
