Provider Indicators
Cross-cutting wireframe showing how provider badges (F18) and cost display variants (F19) appear across the DartClaw UI. Not a standalone page — these patterns are applied to existing pages.

Design Notes
  • Badge sits right-aligned in the session row, after the session name
  • Uses distinct colors: Claude (accent/mauve) vs Codex (info/blue)
  • Badge is small (0.625rem) to avoid crowding the session name
  • When all sessions use the same provider, badges could be hidden (optional — configurable)
  • Channel sessions inherit provider from the channel’s config or from per-session override
