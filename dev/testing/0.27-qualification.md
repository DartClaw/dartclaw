## Candidate identity

A working-tree result is valid only for all of these fields together:

- `kind: working-tree`
- the 40-character `head` from `git rev-parse HEAD`
- an explicit `scope`
- SHA-256 of the staged binary diff
- SHA-256 of the unstaged binary diff
- every untracked input path in scope and its SHA-256

The input scope is `packages apps dev docs CHANGELOG.md pubspec.yaml pubspec.lock analysis_options.yaml`. Generated
results below `.agent_temp/exec-plan-0.27/S09/results/` and `.agent_temp/testing/conversation-loop/` are explicit
output exclusions. Runnable fixture, test, profile, protocol, guide, and architecture files remain candidate inputs.

Capture identity from the verified public repository root before a result:

```bash
mkdir -p .agent_temp/exec-plan-0.27/S09/identity
git rev-parse HEAD >.agent_temp/exec-plan-0.27/S09/identity/head.txt
git diff --cached --binary --no-ext-diff -- packages apps dev docs CHANGELOG.md pubspec.yaml pubspec.lock analysis_options.yaml >.agent_temp/exec-plan-0.27/S09/identity/staged.patch
git diff --binary --no-ext-diff -- packages apps dev docs CHANGELOG.md pubspec.yaml pubspec.lock analysis_options.yaml >.agent_temp/exec-plan-0.27/S09/identity/unstaged.patch
git ls-files --others --exclude-standard -- packages apps dev docs CHANGELOG.md pubspec.yaml pubspec.lock analysis_options.yaml >.agent_temp/exec-plan-0.27/S09/identity/untracked.txt
shasum -a 256 .agent_temp/exec-plan-0.27/S09/identity/staged.patch .agent_temp/exec-plan-0.27/S09/identity/unstaged.patch >.agent_temp/exec-plan-0.27/S09/identity/diff-sha256.txt
while IFS= read -r path; do shasum -a 256 "$path"; done <.agent_temp/exec-plan-0.27/S09/identity/untracked.txt >.agent_temp/exec-plan-0.27/S09/identity/untracked-sha256.txt
```

Do not reduce this to HEAD plus the unstaged diff. A staged-only change must invalidate the identity. The result
directory is outside the input scope so generating a result does not change the identity it records.

A clean release result uses `kind: committed`, an exact `head`, and `porcelainEmpty: true`. Capture it only after all
changes are committed:

```bash
git rev-parse HEAD
test -z "$(git status --porcelain=v1 --untracked-files=all)"
```

The clean result remains pending until the required gates rerun on that SHA. A working-tree pass is never relabelled.
